# Structure-programing-project
Structure programing project
🎓 GradeBook System
نظام إدارة درجات طلاب متكامل تم تطويره باستخدام لغة Java ومكتبة Swing. يهدف النظام إلى تنظيم العملية التعليمية من خلال إدارة بيانات الطلاب، إعداد المواد الدراسية، وتسجيل الدرجات بفعالية.

🚀 المميزات الرئيسية
تسجيل الطلاب: إضافة طلاب جدد بسهولة مع نظام للتحقق من عدم تكرار أرقام الهوية.

إدارة الدورات: إمكانية تخصيص وتعديل أسماء المواد الدراسية (بحد أقصى 5 مواد).

نظام الدرجات: تسجيل درجات الطلاب لكل مادة مع التأكد من مطابقتها للمعايير (0-100).

تقارير الطلاب: عرض تقرير شامل للطالب يتضمن جميع درجاته وحساب المعدل التراكمي الخاص به.

ملخص القسم: استعراض متوسط أداء الطلاب في كل مادة دراسية على حدة.

🛠️ التقنيات المستخدمة
Language: Java

UI: Java Swing (GridLayout, BorderLayout)

Data Structure: Arrays (مصفوفات لتخزين البيانات)

🏗️ هيكل المشروع
Main.java: الكود الرئيسي الذي يحتوي على الواجهة الرسومية (GUI) ومنطق العمليات الحسابية وإدارة البيانات.

⚙️ كيفية التشغيل
تأكد من تثبيت Java JDK.

قم بتحميل ملف Main.java إلى جهازك.

افتح الـ Terminal في المجلد الذي يحتوي على الملف.

قم بعمل Compile للملف: javac Main.java

قم بتشغيل البرنامج: java Main
